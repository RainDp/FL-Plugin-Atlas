# Atlas Studio 界面副本

本版面向长时间使用 FL Studio 的制作人。界面采用不透明材质和单一琥珀色操作层级，以插件名称、用途和预设内容为中心。

## 视觉系统

| 用途 | 值 |
| --- | --- |
| 主背景 / 侧栏 / 预览栏 | `#181A1C` / `#141618` / `#1C1E20` |
| 输入区域 | `#212427` |
| 正文 / 次要信息 / 提示 | `#EFEDE7` / `#A9ADAF` / `#868D92` |
| 主要操作 / 选中背景 | `#E3B763` / `#382F21` |
| 乐器标记 | `#8BBBB5` |
| 中文与正文 | Microsoft YaHei UI；Figma 对应 Noto Sans SC |
| 英文品牌 / 路径与格式 | Segoe UI / Consolas |

厂商与用途位于左栏，组合筛选保持独立；类型切换位于搜索下方。中栏为六行双行信息列表，右栏展示加载操作、预览、用途和来源。底部集中批量编辑与任务状态。无缩略图时采用确定性的信号封面，并明确标记缺图。

## 动效

悬停进入 120 ms、离开 180 ms，按下反馈 75 ms，列表选择 150 ms，图片切换 220 ms。使用可中断的三次缓出，状态改变不移动控件布局。遵循 Windows 减少动画设置，停稳后停止动画计时器。

## 验证

- 5 项 CTest：扫描器、SQLite、CLI、CLAP、Studio UI。
- 新界面验证使用隔离样本：厂商 × 用途 × 类型交集、未知厂商、同名独立身份、搜索、批量数量、长名称、焦点、Esc 清空、减少动画、空闲计时器和 GDI 对象数量。
- 修复 DPI 四舍五入导致六行列表退化为五行的问题。
- 正文/背景 14.91:1，次要文字/背景 7.71:1，提示文字/输入框 4.63:1，选中文字/选中背景 8.84:1，主按钮文字/琥珀背景 9.33:1。
- `review/studio.png`、`instruments.png`、`empty-filter.png`、`long-name.png`、`search-focus.png` 均为新编译 CLAP 的原生控件渲染。
- Computer Use 已查看实际桌面窗口；后续输入时窗口失去目标，未将该部分记作桌面交互验收。筛选和键盘行为由隔离 UI 测试验证。
- 新版尚未在 FL Studio 中完成宿主加载验收；发布到 FL 收藏目录仍为原项目待实现能力。

## 设计参考与工具

应用 UI/UX Pro Max 的平面设计、可读性和减少动画指南，Frontend Design 的行业语境与排版原则，Computer Use 的原生窗口检查流程。使用 Figma MCP 创建可编辑稿，复用 Simple Design System 的按钮与搜索控件；参考 shadcn MCP 的组件结构与审查清单。C++ 实现保留现有原生技术栈，不引入 Web UI 依赖。
